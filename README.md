# کیف‌آرا | قالب فروشگاه کیف

قالب موبایل‌محور فروشگاه کیف با تم شیشه‌ای (glassmorphism) و رنگ‌های طلایی/تیره. **نسخه آزمایشی** و بدون بک‌اند.

## امکانات
- هدر شفاف روی عکس بزرگ (منو، ورود، لوگو، جستجو) با اسلایدر متحرک
- استوری (عکس/ویدیو، لایک، نظر، اشتراک‌گذاری، خاکستری‌شدن دیده‌شده‌ها)
- محصولات با گالری عکس، بزرگ‌نمایی، رنگ‌بندی و سفارش
- منوی کشویی با عکس قابل تعویض
- منوی پایین با حباب مایع متحرک
- سبد خرید، پیگیری سفارش، پرداخت کارت‌به‌کارت
- حالت شب/روز
- **پنل ادمین** برای مدیریت همه‌چیز (اطلاعات، رنگ و شیشه، اسلایدر، منو، استوری، محصولات، سفارش‌ها…)

## اجرا
فایل `index.html` را باز کنید. هیچ نصب یا سروری لازم نیست.

## انتشار روی GitHub Pages
1. مخزن را در GitHub بسازید و فایل‌ها را آپلود کنید.
2. به **Settings → Pages** بروید.
3. در Source گزینه‌ی **Deploy from a branch** و شاخه‌ی `main` با پوشه‌ی `/ (root)` را انتخاب کنید.
4. بعد از چند دقیقه سایت در `https://<username>.github.io/<repo>/` در دسترس است.

## پنل ادمین
- از منوی کشویی گزینه‌ی **ورود مدیر** را بزنید، یا به انتهای آدرس `#admin` اضافه کنید.
- رمز پیش‌فرض: `1234` (حتماً از بخش «تنظیمات» عوض کنید).

## ساختار
```
index.html      # خروجی نهایی (ساخته‌شده از src)
src/style.css   # استایل و تم
src/data.js     # آیکون‌ها، داده نمونه، ذخیره‌سازی
src/app.js      # بخش فروشگاه
src/admin.js    # پنل ادمین
build.sh        # ساخت index.html از src
```
بعد از ویرایش فایل‌های `src` دستور `./build.sh` را اجرا کنید.

## محدودیت نسخه آزمایشی
داده‌ها (محصولات، سفارش‌ها، تنظیمات ادمین) فقط در **مرورگر همان کاربر** ذخیره می‌شوند و بین بازدیدکننده‌ها به اشتراک گذاشته نمی‌شوند. برای فروش واقعی باید بک‌اند (سرور + دیتابیس)، درگاه پرداخت و ورود با پیامک اضافه شود.
